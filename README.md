# CauçãoFlex Landing Page

Protótipo da landing page da CauçãoFlex para testes de experiência e validação.

## Publicar no GitHub Pages

1. Crie um novo repositório no GitHub, por exemplo:
   `caucaoflex-landing`

2. Faça upload dos arquivos deste pacote para a raiz do repositório.

3. No GitHub, acesse:
   **Settings → Pages**

4. Em **Build and deployment**, escolha:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**

5. Clique em **Save**.

Em alguns instantes, o GitHub fornecerá uma URL semelhante a:

`https://SEU-USUARIO.github.io/caucaoflex-landing/`

Compartilhe essa URL para que outras pessoas testem a landing page no celular ou computador.

## Arquivo principal

- `index.html`: landing page completa, incluindo estilos, imagens e JavaScript do simulador.
